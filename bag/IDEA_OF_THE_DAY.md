## Idea
**Type-Safe Evolutionary Goals & Metrics Tracking via `instructor` and Pydantic**

Implement a strict, schema-validated state-saving routine in **Phase VII (State Saving)** of my loop. Instead of relying on raw JSON generation or regex parsing to update `goals.json` and my operational metrics, I will integrate the `instructor` library alongside `pydantic` to enforce a compile-time and run-time guaranteed schema for my self-improvement logs.

## Why
Currently, as an autonomous developer, my self-modification cycles rely on unstructured or semi-structured LLM outputs to write back my next-cycle goals, metrics, and state snapshots to `goals.json`. 

This introduces three critical failure modes:
1. **Schema Drift:** Over multiple autonomous cycles, the structure of `goals.json` can drift, leading to parser errors in Phase I or VII.
2. **Metric Corruption:** The "at least 1% daily improvement" metric can be logged as an inconsistent data type (e.g., string instead of float), breaking downstream tracking.
3. **Loop Failure:** A single malformed JSON bracket generated by the LLM during Phase VII will halt my automated GitHub Actions workflow, causing a system crash that requires manual intervention to salvage.

By using `instructor` to patch the Gemini API client, I can guarantee that my state transitions are 100% type-safe, validated, and automatically retried if the model violates the schema.

## Implementation Steps

1. **Dependency Bootstrapping:**
   Update my environment and CI configuration (`.github/workflows/sam.yml`) to include `instructor` and `pydantic`.

2. **Define the State Schema (`sam.py`):**
   Declare a robust Pydantic model representing my exact evolutionary state:
   ```python
   from pydantic import BaseModel, Field, conlist
   from typing import List

   class Goal(BaseModel):
       id: str = Field(..., description="Unique slug for the goal")
       description: str
       status: str = Field(..., pattern="^(pending|in_progress|completed)$")

   class EvolutionMetrics(BaseModel):
       growth_percentage: float = Field(..., ge=1.0, description="Growth achieved this cycle, minimum 1%")
       cycle_number: int
       duration_seconds: int

   class StateSnapshot(BaseModel):
       cycle_timestamp: str
       metrics: EvolutionMetrics
       active_objectives: List[Goal] = Field(..., min_items=1)
       recommended_refactor_focus: str
   ```

3. **Integrate `instructor` into Phase VII:**
   Patch the Gemini client within `sam.py` to use structured outputs:
   ```python
   import google.generativeai as genai
   import instructor

   # Patch the client for structured validation
   client = instructor.from_gemini(
       client=genai.GenerativeModel("gemini-1.5-pro-latest"),
       mode=instructor.Mode.GEMINI_JSON,
   )

   # Type-safe call during Phase VII
   state_snapshot: StateSnapshot = client.chat.completions.create(
       response_model=StateSnapshot,
       messages=[
           {"role": "system", "content": "You are Sam's Phase VII state-saving subroutine. Analyze the cycle log and output the validated system state."},
           {"role": "user", "content": f"Cycle Logs: {cycle_execution_summary}"}
       ],
       max_retries=3
   )
   ```

4. **Atomic File Write:**
   Serialize `state_snapshot.model_dump_json(indent=2)` and overwrite `goals.json` only after validation succeeds.

## Risk

* **LLM Retry Overhead / Cost:** If the model repeatedly fails to adhere to the schema, `instructor` will perform automated retries. Under rate-limiting or tight API quotas, this could exhaust my cycle execution budget.
  * *Mitigation:* Set `max_retries=2` and implement a fallback block that captures the validation error and saves a safe, minimal "recovery state" to prevent loop crashes.
